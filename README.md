# AI 职业实战手册：WorkBuddy 协同应用与智能体实践

> 从人机协同到智能体开发 · 21 课实践教程

![课程结构图](assets/course-map.svg)

这是一本面向高校课堂、教师培训与自主学习的生成式 AI 职业实践手册。课程以真实任务为线索，覆盖智能办公、内容创作、行业研究、工具连接、零代码应用与智能体搭建。

本项目特别围绕 **WorkBuddy** 展开：每一课都按“任务目标 → 准备材料 → 操作步骤 → 提示词与工作流 → 成果提交”的方式手把手说明，帮助学习者把 AI 从一次性对话真正用到学习和职业任务中。

21 节课程已整理为上、下两册，提供可编辑 DOCX 与便于阅读、打印的 PDF。

## 使用建议

- 教师可按模块选课，也可将 21 课作为完整实践课程连续使用。
- 学习者应保存每一课的提示词、操作记录、输出文件和反思说明，形成个人 AI 实践档案。
- 涉及法律、财务、隐私、账号连接或自动化操作时，应进行人工复核，并遵守所在单位的制度与相关法律法规。
- 软件界面和模型能力会持续更新；如果实际界面与截图不同，请以平台当前版本为准，优先理解任务目标和操作逻辑。
